About Us

Best Cars Dealership has been connecting drivers with their perfect vehicle since 1995.

This portal is the capstone project for the IBM Full-Stack Developer Professional Certificate. It demonstrates a microservices architecture combining Django, React, Node/Express, MongoDB, Flask, Docker and Kubernetes.

Architecture

Browser → Django (main site + proxy)
            ├── SQLite        (car makes/models)
            ├── React         (auth UI)
            └── Express API   (dealers + reviews)
                    └── MongoDB
            └── Sentiment service (Flask)
